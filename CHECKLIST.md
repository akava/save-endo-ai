# Чеклист перед коммитом улучшения

Каждый раз, когда найдено улучшение (новый префикс):

1. `tools/build_best.py`: патч добавлен в `ORDER`, параметры в `PARAMS`; `python tools/build_best.py prefixes/NN_name.dna`.
2. Проверен счёт `prefixes/NN_name.dna` точной метрикой (`score()` против `doc/Target-image-600.png`).
3. `reports/findings.md`: раздел «Улучшение N» (что нашли, как, цифры) и строка в таблице «Префиксы».
4. `reports/process.md`: что поняли о самом процессе (если есть урок).
5. `reports/story.md`: глава для ребёнка (простые слова, картинка).
6. `reports/story_noir.md`: глава детектива (стиль нуар, без «детских» слов; это фотография, а не картинка).
7. `reports/img/`: только отобранные картинки (было / стало / target).
8. `README.md` и `NEXT_SESSION.md`: лучший префикс, длина, число неверных пикселей.
9. `git add` всех новых файлов (инструменты, картинки, префиксы), коммит, `git push origin main`.
